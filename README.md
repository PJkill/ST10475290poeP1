# 📩 Java Console Chat Application

This is a simple Java-based console chat application that allows users to register, log in, and exchange messages. It features user input validation, message sending/viewing, and basic account management.

---

## 🛠 Features

- ✅ *User Registration* with validation (username, password, cell phone number)
- 🔐 *Login* with verification of stored credentials
- 💬 *Send & View Messages* (messages include read/unread status)
- 🧪 *Validation Rules* for username, password, and phone number
- 🧾 *JUnit Test Cases* available to validate methods

---

## 📋 Requirements

- Java JDK 8+
- Apache NetBeans 18 (or any Java IDE)
- JUnit 5 (for running test cases)
